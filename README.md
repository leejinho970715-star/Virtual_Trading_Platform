# 껄무새 투자거래소

원본 https://my-landing-delta-seven.vercel.app/ 의 공개 동작과 계산 방식을 확인해 재구현한 모의투자 웹사이트입니다.

## 실행

Node.js 22 이상에서 `npm start` 후 http://localhost:4173 에 접속합니다. 외부 패키지 설치가 필요 없습니다.

- `npm test`: 매수·매도·평균 매수가·한도·다음 날 계산 검증
- `npm run build`: GitHub Pages용 정적 파일을 `dist/`에 생성
- main 브랜치에 push하면 GitHub Actions가 검사 후 Pages에 배포합니다.

## 유지한 기능과 규칙

6개 가상 종목, 기본 1,000 코인, 코인 단위 매수·매도, 가중평균 매수가와 포트폴리오 수익률, 프로필·시작 코인 설정, 포트폴리오 초기화 및 계정 리셋을 제공합니다. 다음 날은 5초 후 계산됩니다. 셀프컴퍼니는 기본 +50~+100%, 나머지 종목은 -5~-30%로 하락합니다. 기존 매수가보다 높은 비셀프 종목은 매수가 아래로 조정됩니다. 셀프컴퍼니 보유 시 비중과 무관하게 전체 평가액이 원금과 직전 평가액보다 최소 1% 높도록 셀프컴퍼니 상승폭을 추가 조정합니다. 적용 코인은 시작 코인 × (1 + 전체 투자 수익률)이며, 투자 가능 코인은 적용 코인에서 보유 수량을 뺀 값입니다. 이 규칙은 현실 증권 거래 방식이 아닙니다.

원본의 관심 등록, 전체 종목 보기, 투자 팁 더 보기는 안내 메시지를 표시하는 기능이므로 동일하게 재현했습니다. 초기화에는 실수 방지를 위한 확인 창을 추가했습니다. 계정 기록은 이 브라우저에만 저장되며 원본 사이트 계정과 공유되지 않습니다. 원본과 달리 다음 날의 시세·적용 코인도 새로고침 후 유지합니다.

## 새 UI

네이비·민트 글래스모피즘, 앵무새 코인 로고와 3D 렌더 에셋, 움직이는 라인 차트와 캔들 전환, 가격 눈금·거래량·호버 추적선, 키보드 차트 탐색, 입체 버튼, Web Audio 주문 효과음, 음소거, 반응형 화면을 제공합니다. 차트의 장중 시계열과 거래량은 표시용 합성 데이터이며 실제 거래 시세가 아닙니다. 움직임은 평가 금액을 바꾸지 않으며 계정 시세는 다음 날 기능으로만 변경됩니다. 운영체제의 모션 감소 설정을 지원합니다.

## 에셋

`assets/parrot-yellow.png`, `assets/parrot-red.png`, `assets/glass-portfolio.png`, `assets/glass-market.png`는 내장 image_gen으로 생성한 투명 배경 3D 렌더 이미지입니다. 실시간 3D 모델 파일은 아닙니다. 이모지나 평면 아이콘 라이브러리는 사용하지 않습니다. 로고와 종목 표식 등에 동일 에셋을 재사용합니다. 프롬프트는 `ASSETS.md`에 기록했습니다.


## 수익 결과 코인

다음 날 계산 완료 시 총 포트폴리오 수익률이 양수이면 노란 앵무새 코인, 음수이면 빨간 앵무새 코인을 결과 창과 수익률 카드에 표시합니다. 0% 또는 미투자는 중립 결과로 표시합니다. 코인 종류는 시각적 피드백이며 별도 자산이나 통화가 아닙니다.

## 정글 테마와 브랜드

전체 배경은 생성한 야간 정글 이미지이며 콘텐츠 패널은 backdrop blur와 반투명 표면으로 구성됩니다. 보유 코인 장식은 축소했고 헤더는 별도 초록 앵무새 코인 로고를 사용합니다. 파비콘은 32/192px, Apple Touch Icon은 180px, Open Graph 이미지는 1200×630 JPEG입니다. 모든 웹 텍스트와 차트 눈금은 자체 호스팅하는 Pretendard Variable v1.3.9를 사용합니다. 폰트 출처와 SIL OFL은 assets/fonts/OFL.txt 및 assets/BRANDING-ASSETS.md를 참고하세요.

## 메인 비주얼과 시뮬레이션 우선 종목

사용자 제공 배너를 헤더 아래에 배치했으며 배너를 누르면 모의 주문 화면으로 이동합니다. 이미지는 원본 비율을 유지합니다.

메인 페이지는 결과가 정해진 모의 시나리오입니다. 셀프컴퍼니 포함 시 다음 날 총수익은 양수, 다른 종목만 보유하면 음수입니다. 손익 코인은 방향에 따라 올림/내림해 정수 표시에도 반영합니다. 동시에 최대 2개 종목에 투자할 수 있으며 보유 종목 추가 매수와 전량 회수 후 종목 교체를 지원합니다. 기존 3개 이상 보유 기록은 삭제하지 않으며, 2개 이하로 회수하기 전에는 매수와 다음 날 진행을 제한합니다. 제한은 기존 브라우저 저장 계좌 기준이며 신원 확인이나 기기 간 통합 제한은 없습니다. 별도 terminal과 Live Chart TV의 랜덤 시세는 변경하지 않습니다.

## 별도 차트 화면

새 차트 화면은 /terminal/ 에서 열립니다. 7개 종목의 모의 시세, 캔들, 거래량, MA/MACD/RSI, 호가가 함께 갱신됩니다. 검색, 종목 선택, 지표 표시, 시간 간격 변경, 시세 일시정지 및 가상 매수·매도를 지원합니다. 기존 메인 거래소와 별도 계좌이며 새로고침하면 초기화됩니다.


## Live Chart TV

/live-chart-tv/ 는 관심종목, 차트, 매수·매도 호가만 표시하는 별도 화면입니다. 뷰포트 높이에 맞게 배치되며 작은 화면에서는 전체 보드를 축소하여 스크롤 없이 표시합니다. 기존 terminal 페이지와 같은 시세·주문 모듈을 공유합니다.


## 결과 해설

다음 날 결과 창에서 보유 종목별 수익률과 상승·하락 시나리오를 함께 표시합니다. 셀프컴퍼니는 자기 돌봄의 기반, 나머지 종목은 기대와 실제 실행 사이의 차이를 설명합니다. 해설은 가상의 교육용 이야기이며 실제 시장 뉴스나 실증된 수익 원인이 아닙니다.


## 표시 시세와 결과 분리

메인 화면의 인기 종목, 선택 종목 가격·등락률 및 차트는 display-market.js의 연출용 시세를 사용합니다. 모든 종목이 약 1.8초마다 랜덤으로 오르내리며 기준 가격은 최초 표시용 가격입니다. 주문·보유 수익률·결과 코인·종목별 해설은 기존 engine.js의 시나리오 계산을 사용합니다. 연출용 갱신은 계좌 상태에 저장되지 않으며 결과 창과 다음 날 처리 중에는 멈춥니다.
